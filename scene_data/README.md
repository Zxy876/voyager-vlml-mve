# scene_data/ —— 场景的工作区（应用自己在用，用户不用配）

**这不是「让你先准备数据」的目录。** 一般用户是把应用下载下来、放在自己电脑上跑，
数据自然就在这台机器上 —— 用户不需要配库、也不需要往这里手工放东西。

- 建一个场景，这里会自动出现 `scene_data/<场景 id>/`；
- 应用自己产生的数据（导出的表、笔记、场景库）默认落在这里；
- 已有现成的 `*.json` / `*.csv` / `*.duckdb` 想一起查，丢进来即可（可选）。

## 边界（刻意收紧）

- **只读**：没有 write / delete；
- 只允许落在**应用工作区**和**场景目录**内；
- **不读操作者的家目录** —— 「数据源就是本机」指的是应用跑在这台机器上，
  不是去翻用户的私人文件（2026-10-19 用户纠正）；
- 模型写的代码跑在受限命名空间里：没有 `import`、没有 `open`，单次执行有超时。

## 什么时候会「没有数据」

在这种场景里问一个本机没有的问题（例如「现在最前沿的世界模型是什么」），
答案是**如实说没有**：`本机工作区里没有能回答它的数据 …… 这类问题需要外部数据源`。
不会退回 VLML/rib 库去凑一个答案（那正是"问世界模型却答出战队列"的事故）。
