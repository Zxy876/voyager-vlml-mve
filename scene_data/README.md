# scene_data/ —— 场景的本机数据（普通用户的数据源）

**这是给普通用户的那一档：不用配任何库。** 建一个场景，这个目录下就会自动出现
`scene_data/<场景 id>/`；把要用的文件丢进去，Voyager 学习与导入消费就只读这里。

对照猫娘（N.E.K.O）：它的工具层里没有"数据库"这一档 —— `app_launcher` /
`lifekit` / `music` / `web_search` 全是本机/外部能力，用户从来没"配数据源"
这一步。MVE 的场景后端同理：**插件即本机能力，本机就是数据源**。

## 放什么

| 放进来 | 怎么被读到 |
|---|---|
| `*.json` / `*.csv` / `*.txt` / `*.md` | 本机原语 `list_files` / `read_file` |
| `*.duckdb` | 本机原语 `query_sql`（只读；场景目录里有库时后端自动切 `scene`） |

## 谁能读

只读、路径受限：本机原语只允许落在**场景目录**和**家目录**下，`..` 与绝对
路径都做校验；模型写的代码跑在受限命名空间里（没有 `import`、没有 `open`），
单次执行有超时。没有 write / delete。

## 别放什么

凭据、密钥、整个家目录的副本。这里是给"问一句、从本机取个数"用的，不是备份盘。
